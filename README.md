# 🗄️Compress-file-and-folders-using-python-script

This simple Python script creates a **.zip backup** of a specified source folder and stores it in a specified destination folder. The backup file is named with the current date for easy version tracking.

---

## 📁 Features

- Automatically generates a `.zip` backup file.
- Includes the current date in the filename (e.g., `backup_2025-05-03.zip`).
- Simple to configure and extend.
- Uses built-in Python libraries: `shutil`, `os`, and `datetime`.

---

## 🧾 How It Works

1. You define the **source** folder (the one you want to back up).
2. You define the **destination** folder (where the `.zip` backup will be saved).
3. The script creates a backup with today's date.
